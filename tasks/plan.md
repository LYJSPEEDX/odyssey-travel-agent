# 首页与本机行程库

用户已确定：首页横幅进入五步规划，下方展示示例；底部为 Home、My Trips、Settings。My Trips 保存生成过的行程，无数据时显示“No trips yet”。设置包含账号、资料、偏好、关于、版本。界面文案全部使用英语，用户输入保留原文。继续采用假数据，不接接口。

## 实现顺序

1. 本机行程库：用独立 SharedPreferences 条目保存每条行程的 JSON 快照；生成成功后保存，同一次生成使用稳定 ID，重建不重复保存。读取失败显示错误，不覆盖已有记录。设备重启仍可读取。
2. 首页壳：新增 HomeActivity 作为启动页；Material BottomNavigationView 三项固定底部。现有 MainActivity 保留五步规划，第一步后退回首页。首页示例明确标注，不计入我的行程。
3. 我的：空状态、倒序行程卡片、点击查看保存的摘要与演示内容；结果页可直接打开“我的”。
4. 设置：账号入口解释未接服务；修改本机昵称；主题跟随系统/浅色/深色并持久保存；关于、读取安装包版本。无密码输入、无假登录。
5. 回归：编译、单元测试、模拟器验证保存重读、去重、空态、三个标签、返回、主题恢复和五步原流程。

## 边界

- 保存内容是本地演示行程，不是报价或预订；自由输入仍不经 AI 解析。
- 本机存储不等于云同步；卸载/清除应用数据会移除本机记录。暂不提供删除或云同步功能。
- 页面优先保持现有配色、圆角和 Java/XML；不重构既有表单、不增加第三方依赖。
- 每段实现后检查；不自动提交 Git，不覆盖用户既有改动。
